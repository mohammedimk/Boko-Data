# VTU Hub — Automated VTU & Data Selling Platform

A production-ready Django 5 web application for selling airtime, data bundles,
cable TV subscriptions, and electricity tokens, with wallet funding via
Paystack and a dynamically generated virtual bank account for every user
(similar in spirit to CheapDataHub).

## Features

- **Authentication** — registration, login, logout, password reset, and a
  personalised dashboard, built on Django's auth system + a `UserProfile` model.
- **Wallet system** — fund your wallet via Paystack (test mode): initialize →
  redirect → verify → credit wallet, all logged as `Transaction` rows.
- **Dynamic virtual bank account** — every user gets a mock dedicated account
  (bank name, account number, account name derived from their real name) the
  moment they register, generated by `VirtualAccountService` in `core/utils.py`.
  Swap the mock for a real provider (Monnify, SquadCo, Flutterwave, Paystack
  Dedicated Accounts) by replacing `_mock_generate`/`_live_generate` — no other
  code needs to change.
- **Buy Data** — network-aware, AJAX-driven plan list (change network → plans
  reload instantly with no page refresh) via `CheapDataHubAPI.get_data_plans`.
- **Buy Airtime** — MTN, Airtel, Glo, 9mobile; VTU or Share & Sell.
- **Cable Subscription** — DSTV, GOTV, StarTimes with smart card / IUC
  validation and dynamic bouquet pricing.
- **Electricity Bills** — prepaid & postpaid, meter validation, and token
  display on successful payment.
- **Balance validation** — every purchase checks `wallet_balance >= price`
  inside a DB transaction with row locking (`select_for_update`) before
  debiting, calling the provider, and logging the transaction. Provider
  failures automatically refund the wallet.
- **Admin panel** — manage Users (with inline wallet/profile), and dedicated
  admin sections for Data, Airtime, Cable, and Electricity transactions.
- **Security** — CSRF protection, `login_required`/custom decorators, input
  validation via Django forms, atomic transactions, exception logging to
  `logs/vtu_platform.log`, and environment-variable-based secrets.

## Tech Stack

Python 3.13+, Django 5+, Bootstrap 5, vanilla JS + AJAX (`fetch`), SQLite
(dev) / PostgreSQL-ready, Paystack API (test mode), CheapDataHub API client
(with a built-in realistic mock provider so the app runs fully offline/demo).

## Getting Started

1. **Create a virtual environment & install dependencies**
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Configure environment variables**
   ```bash
   cp .env.example .env
   ```
   Edit `.env` with your own `DJANGO_SECRET_KEY`, and (optionally) your real
   Paystack test keys from https://dashboard.paystack.com. Leave
   `VTU_USE_MOCK_PROVIDER=True` to run the whole app — including data plans,
   airtime, cable, and electricity — against the built-in mock CheapDataHub
   provider with no external account needed.

   > This project reads env vars directly via `os.environ`. If you use the
   > `.env` file, load it before running Django, e.g. with
   > `export $(cat .env | xargs)` on Linux/macOS, or add `python-decouple` /
   > `django-environ` wiring in `settings.py` for automatic loading.

3. **Run migrations**
   ```bash
   python manage.py migrate
   ```

4. **Create a superuser** (for the admin panel)
   ```bash
   python manage.py createsuperuser
   ```

5. **Run the development server**
   ```bash
   python manage.py runserver
   ```
   Visit `http://127.0.0.1:8000/register/` to create an account — a wallet
   and virtual bank account are generated for you immediately.

## Going Live

- **Paystack**: replace the test keys in `.env` with your live secret/public
  keys and update `PAYSTACK_CALLBACK_URL` to your production domain.
- **CheapDataHub**: set `VTU_USE_MOCK_PROVIDER=False` and provide
  `CHEAPDATAHUB_API_KEY` / `CHEAPDATAHUB_BASE_URL`. `CheapDataHubAPI` will
  then make real HTTP calls instead of returning mock data — no view code
  needs to change.
- **Virtual accounts**: implement `VirtualAccountService._live_generate` with
  your chosen banking partner's real API and flip `VTU_USE_MOCK_PROVIDER` off.
- **Database**: set `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`,
  `POSTGRES_HOST`, `POSTGRES_PORT` to point at your PostgreSQL instance —
  `settings.py` automatically switches from SQLite when these are present.
- **Static files**: run `python manage.py collectstatic` and serve via
  Whitenoise/Nginx; set `DJANGO_DEBUG=False` and configure
  `DJANGO_ALLOWED_HOSTS` / `CSRF_TRUSTED_ORIGINS`.

## Security Notes

- Never commit `.env` or real API keys — `.gitignore` already excludes `.env`.
- All wallet debits/credits happen inside `transaction.atomic()` blocks with
  `select_for_update()` to prevent race conditions on double-spends.
- Provider (CheapDataHub) failures automatically trigger a wallet refund.
- All external API responses are stored in `Transaction.api_response` (JSON)
  for audit trails.
